# FabOps Control Center

Production-style semiconductor manufacturing operations and equipment simulation system.

## Current Project

### Equipment Simulator

A WPF application targeting .NET Framework 4.8 that simulates semiconductor manufacturing equipment.

## Current Status

Milestone 1 - Project Foundation

- GitHub repository created
- Visual Studio solution created
- Equipment Simulator WPF project created
- Target framework: .NET Framework 4.8

## Planned Communication

Initial communication:

Equipment Simulator ↔ TCP/IP ↔ XML ↔ FabOps

Future direction:

TCP/XML communication will evolve toward concepts based on SEMI E5, E30 and E37/HSMS.

## Project Goals

- WPF / MVVM
- Equipment simulation
